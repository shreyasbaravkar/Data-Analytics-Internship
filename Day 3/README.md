# Task 3 - SQL for Data Analysis

## 📌 Objective
Perform SQL-based data analysis using PostgreSQL on an E-commerce dataset.

## 🛠️ Tools Used
- PostgreSQL
- pgAdmin 4

## 📂 Dataset
E-commerce Dataset.csv

## 📋 SQL Concepts Covered
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- SUM()
- AVG()
- COUNT()
- Subqueries
- Views
- Indexes

## 📊 Queries Performed

1. Display all records.
2. Filter records using WHERE.
3. Sort records using ORDER BY.
4. Calculate total sales by product category.
5. Calculate average profit by product category.
6. Count orders by payment method.
7. Use a subquery to find sales greater than average.
8. Create and use a VIEW.
9. Create an INDEX for faster searches.

## ✅ Outcome
Successfully performed SQL data analysis using PostgreSQL by executing queries for filtering, sorting, aggregation, subqueries, views, and indexing.
